## Qué Hice (Tech + Leadership)

### Backend: Seguridad + Escalabilidad
```
✓ API REST escalable (Node/Express)
✓ Autenticación stateless (JWT + Passport)
✓ Validación en capas (Joi schemas)
✓ Persistencia flexible (MongoDB Atlas)
✓ Almacenamiento ilimitado (AWS S3)
✓ Error handling estructurado (Boom)
✓ Containerizado (Docker)
```

**Decisión clave**: Stateless authentication para escalabilidad horizontal — cualquier servidor puede validar tokens.

### Frontend: UX Reactiva + Mantenible
```
✓ State management centralizado (Redux + Persist)
✓ Componentes reutilizables (20+)
✓ Theming dinámico (Chakra UI)
✓ Animaciones fluidas (Framer Motion)
✓ Validaciones en tiempo real
✓ Token lifecycle automático
```

**Decisión clave**: Redux + Persist para session recovery automática — usuario recarga página y UX continúa donde se dejó.

### Infraestructura: Deploy Production-Ready
```
✓ Docker (dev-prod parity)
✓ Monorepo organizado (/api, /client)
✓ Environment management
✓ Multi-stage builds
```

| Aspecto | Impacto |

## Cómo Evaluarme

### Código

### Decisiones

- Redux para state centralizado
- S3 para archivos (no local storage)
